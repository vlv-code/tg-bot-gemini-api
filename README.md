# 🤖 Telegram Bot for Google Gemini API

Асинхронный Telegram-бот на базе **aiogram 3** и официального **Google GenAI SDK (`google-genai`)** с поддержкой актуальных моделей Gemini (3.5 Flash Lite, 3.1 Flash Lite, 3.7 Flash, 3.5 Flash, 2.5 Flash), мультимодальности (фото, PDF, голосовые), генерации речи (TTS), постоянного хранилища SQLite (`aiosqlite` в WAL-режиме) и защиты от спама.

---

## ✨ Возможности

- 📱 **Единое интерактивное меню (`/menu`)**:
  - Удобная навигация по всем разделам с кнопками **«◀️ Назад»** без замусоривания чата.
  - Мгновенное редактирование текущего сообщения без лишних запросов.
- 🤖 **Выбор основной модели Gemini**:
  - Переключение моделей (`gemini-3.5-flash-lite`, `gemini-3.7-flash` и др.) в один клик.
- 🎙 **Гибкая настройка TTS и синтеза речи**:
  - Выбор модели для TTS (`gemini-3.1-flash-tts-preview`, `gemini-2.5-flash` и др.).
  - Выбор голоса озвучки (`Aoede`, `Kore`, `Puck`, `Fenrir`, `Charon`).
  - Быстрое включение/отключение голосовых ответов бота.
  - Прямая озвучка любого текста командой `/tts <текст>`.
- 🖼 **Мультимодальность**:
  - **Фото / Изображения**: отправьте фото с вопросом (или без) — Gemini распознает и проанализирует его.
  - **Документы (PDF / текст)**: отправьте файл для анализа, перевода или резюме.
  - **Голосовые сообщения**: бот слушает голосовые сообщения в Telegram и может отвечать на них голосом.
- 💾 **Персистентное хранилище (SQLite + `aiosqlite`)**:
  - Переиспользуемое соединение и **WAL-режим** (`PRAGMA journal_mode = WAL`) для параллельной работы без блокировок.
  - Автоматические миграции базы данных без потери истории.
  - Сохранение настроек каждого пользователя и истории в volume `./data:/app/data`.
- 🎨 **Rich-форматирование**:
  - Конвертация Markdown в Telegram `MessageEntity` через `telegramify-markdown` (без битой разметки и без проблем с экранированием).
  - Корректный подсчёт UTF-16 code units для безопасного разбиения длинных сообщений.
- 📝 **Индивидуальный System Prompt**:
  - Настройка персонального характера и роли модели для каждого пользователя через `/prompt`.
- ⚡️ **Inline Mode**:
  - Обращение к боту из любого чата (`@bot_username ваш вопрос`).
- 🛡 **Защита от спама и гонок**:
  - Скользящее окно рейт-лимита (в минуту и в сутки).
  - Асинхронные блокировки (`asyncio.Lock`) на пользователя.
- 🔒 **Контроль доступа**:
  - Белый список `ALLOWED_USER_IDS` через Outer Middleware.
- 🐳 **Готовность к Docker**:
  - Автоматическая настройка прав volume через `gosu` и запуск от пользователя `bot` (UID 1000).

## 🌐 Сеть и трафик: Long Polling vs Webhook

Бот работает через **Long Polling** (`dispatcher.start_polling()` в [`bot.py`](bot.py)), а не через webhook.

### Как устроен трафик при Polling:
1. **Исходящее соединение к Telegram**: бот сам исходящим HTTPS-запросом стучится в `api.telegram.org` методом `getUpdates` и держит запрос открытым 30–60 секунд, ожидая новые апдейты. Telegram никогда не коннектится к вашему серверу, инициатор всегда бот.
2. **Исходящее соединение к Gemini**: запросы к Gemini API (`generativelanguage.googleapis.com`) — это тоже обычный исходящий HTTPS.

### Преимущества такой архитектуры:
- 🚫 **Входящих портов открывать не нужно вообще ни одного**.
- 🚫 **Реверс-прокси (Nginx/Traefik) не нужен**.
- 🚫 **Домен и SSL-сертификат не нужны** — бот работает за NAT и серым IP.
- ✅ **Единственное требование к firewall** — разрешённый исходящий порт `443`.
- 🛡 **Надёжность процесса** — в `docker-compose.yml` настроено `restart: unless-stopped`.

## 🚀 Быстрый старт

### 1. Клонирование и настройка окружения

```bash
git clone https://github.com/vlv-code/tg-bot-gemini-api.git
cd tg-bot-gemini-api
cp .env.example .env
```

Заполните переменные в `.env`:
- `TELEGRAM_BOT_TOKEN`: токен бота от [@BotFather](https://t.me/BotFather).
- `GEMINI_API_KEY`: API-ключ от [Google AI Studio](https://aistudio.google.com/).
- `ALLOWED_USER_IDS`: ваш Telegram ID (узнать можно у [@userinfobot](https://t.me/userinfobot)). Оставьте пустым для публичного режима.

---

### 2. Запуск через Docker Compose (рекомендуется)

```bash
docker compose up -d --build
```

Просмотр логов:
```bash
docker compose logs -f
```

---

### 3. Локальный запуск (без Docker)

Требуется **Python 3.12+**.

```bash
python -m venv .venv
# Linux / macOS:
source .venv/bin/activate
# Windows:
.venv\Scripts\Activate.ps1

pip install -r requirements.txt
python bot.py
```

## 🛠 Команды бота

Команды регистрируются в Telegram автоматически при старте бота через `bot.set_my_commands()`:

- `/menu` — **Главное интерактивное меню** (все настройки, выбор моделей, озвучка и параметры).
- `/start` — приветствие и запуск главного меню.
- `/model` — быстрый выбор основной модели Gemini.
- `/settings` — параметры чата (rich-режим, голосовые ответы, очистка истории).
- `/prompt` — просмотр, изменение или сброс системного промпта.
- `/tts <текст>` — озвучить текст голосовым сообщением выбранной TTS моделью и голосом.
- `/limits` — проверка остатка лимитов запросов.

## ⚙️ Настройка в Telegram (@BotFather)

- **/setcommands** — меню команд регистрируется автоматически кодом при запуске бота.
- **/setinline** — **обязательно включите**, если хотите использовать инлайн-режим (`@bot_username вопрос` в любых чатах).
- **/setprivacy** — режим приватности в группах (`Enabled` по умолчанию).
- **/setdescription**, **/setabouttext**, **/setuserpic** — описание и аватарка бота.
